Settings

Solana

Configure your Solana settings. Make sure to use a private RPC endpoint that will not rate limit you. Do not use the default RPC.

The HTTP endpoint URL for your Solana RPC.

The WebSocket endpoint URL for your Solana RPC.

Skip preflight checks before sending transactions. This can speed up transaction sending but may result in failed transactions. Some RPCs do not support preflight checks.

The priority fee (SOL) for transactions. If you set this too low transactions may not land.

Jito

Configure your Jito settings. Jito is used for token launches and all buys and sells (individual and bundle).

The Jito location for validating transactions. Select the closest location to you for optimal performance.

The maximum allowed tip (SOL) for Jito bundles. If you set this too low bundles may not land.

The maximum allowed tip (SOL) for Jito transactions. If you set this too low transactions may not land.

Choose an optional Jito forwarder for optimal performance.

Astralane

Configure your Astralane settings. Astralane is a Jito forwarder that optimizes for speed and fees.

The Astralane location for sending transactions. Select the closest location to you for optimal performance.

Optionally provide your API key for Astralane. This is not required, but it can improve performance and reliability since you won't have to share the rate limit with other users.

The min priority fee (SOL) for Astralane transactions.

The max priority fee (SOL) for Astralane transactions.

Proxies

Proxies are not required.

Add each proxy in the format: host:port:username:password. Separate each proxy with a new line.

Launchpad

Configure your slippage settings for buys and sells for tokens that have not yet bonded, and are still on the launchpad (Pump.fun, Bonk, etc.).

Allowed slippage for launchpad buy orders (i.e. 50 = 50% slippage). If you set this too low, orders may not fill due to price volatility.

Allowed slippage for launchpad sell orders (i.e. 50 = 50% slippage). If you set this too low, orders may not fill due to price volatility.

DEX

Configure your slippage settings for buys and sells on decentralized exchanges after your token has bonded and migrated (Pumpswap, Raydium, etc.).

Allowed slippage for DEX buy orders (i.e. 5 = 5% slippage). You typically want this to be set low because you need to have x + (x * slippage) to fill the order.

Allowed slippage for DEX sell orders (i.e. 50 = 50% slippage).

Customization

Customize your experience to help you launch better and faster.

Choose the default transaction executor. You can override this on a per-task basis.

Customize the quick buy options on the token holdings menu.

Customize the quick sell options on the token holdings menu.

Select which links to automatically open in your default browser after every token launch.

Hide wallet addresses across the application. This is good when you are screen sharing/recording.
