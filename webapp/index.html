Tag 0 Wallet

💡 How Tagging Works

Tagging performs a small buy and sell on a real token pair. Trading dashboards (GMGN, Photon, Axiom, and others) detect the activity and attach their logos to your wallets. The result: your wallets show up across these platforms as verified traders or bots.

Before You Start

  • ✓ Select wallets using the table checkboxes.
  • ✓ Pick an executor that matches your infrastructure.
  • ✓ Choose the trading platforms you want to signal.

After Tagging

  • ✓ Review the wallet on gmgn.ai or other explorers.
  • ✓ Tags may take a few minutes to propagate across platforms.
  • ✓ Re-run tagging whenever you need to refresh visibility.
⚠️

Heads up!

The amount you enter is not how much the tag will cost, but the SOL amount used for the swap. The token is sold back 10–15 seconds later, so expect roughly the same SOL minus network fees. Some platforms can take a few minutes before the tag visibly updates.

Select Wallets to Tag

Pick wallets from the table. Selected wallets appear below so you can inspect balances, existing tags, and switch the active wallet when working in Specific mode.

  3. Apply the matching tag below. Chaos Bot now mirrors the platform label while the on-chain activity still routes through your setup.

How rent reclaim works

Chaos Bot will close inactive token accounts across the selected wallets and consolidate the recovered SOL into the destination address. The operation runs entirely on-chain and can take a few minutes depending on RPC throughput.

All reclaimed SOL (minus transaction fees) will be sent here.

When enabled, Chaos Bot closes token accounts with zero balance to return their rent deposit.

Leave unchecked to reclaim rent only from the wallets you have selected in the table.
